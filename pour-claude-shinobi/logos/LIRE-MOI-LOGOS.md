# Logos AJ pour Claude

- `logo-aj-silhouette.svg` : silhouette vectorielle retracée depuis le JPG fourni. Ce n’est pas le fichier vectoriel original de la marque.
- `logo-aj-toile-bleue.svg` : cette silhouette remplie d’une toile bleue décorative. Le contour est vectoriel, mais le motif est un PNG embarqué dans le SVG : ce logo n’est donc pas 100 % vectoriel.

Les deux SVG sont autonomes : aucune image ni ressource externe n’est nécessaire. Les fichiers sont des copies inchangées des versions conservées dans `assets/logo/`.

Le motif bleu est exclusivement décoratif. Ne jamais le substituer aux vrais tissus, motifs, broderies ou détails des créations photographiées.

Antoine conserve le logo, mais a rejeté la maquette de site V8. La livraison de ces logos ne valide pas sa mise en page.
